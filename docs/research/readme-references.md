## Hero and animated media

| README | Medium | Size |
|---|---|---|
| AltTab | **Animated SVG** (`docs/readme/main.svg`, generated by `scripts/build_readme_svg.py`): SMIL `<animate>` / `<animateTransform>` over 3 embedded JPEG frames and a WebP icon, 8 s loop, 900 px wide, title and download button drawn in the same SVG | 391 KB |
| Gifski | GIF demo | 370 KB |
| Loop | GIF demo (`assets/graphics/loop_demo.gif`) | 17.9 MB |
| Loop, Ice, Pearcleaner feature clips | MP4 / MOV uploaded as `github.com/user-attachments` | 0.7–8.3 MB each |
| Cap | static PNG cover | — |
| LocalSend | static WebP screenshots | 18–56 KB |

Screenshots served as `user-attachments` PNG run from 48 KB to 5 MB.

**(inference)** AltTab's crisp, light hero comes from the animated SVG, not from a GIF: a few still frames with transforms weigh a fifth of what a GIF of the same length would. A GIF in the 0.4–5 MB range is the reasonable target; Loop's 18 MB is the case to avoid. A video in a README plays only from a `user-attachments` upload, so it is not used here (issue 27 commits its output to `docs/readme/`).
